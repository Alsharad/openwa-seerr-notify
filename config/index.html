Your Seerr server

Fills notifications out with the overview, rating, cast and season status. Leave it blank and messages still send, carrying only what the webhook itself provides.

Seerr → Settings → General → API Key. Stored masked; leave the masked value alone to keep the saved key.

The health-check button on the plugin row tests these: it reports the Seerr version and whether the key was accepted.

Who can be notified

Everyone on your Seerr server. Tick a person and give them a WhatsApp number to start notifying them. Names and admin status come from Seerr.

Who gets what

Click a cell to flip it. Requester is the person behind the event; admins is every notified recipient Seerr marks as an admin. Someone who is both gets one message — the admin one.
